## Projects

### PhysioLink

A multi-tenant platform for physiotherapy clinics, built on my own. It has three parts: a Flutter patient app, an ASP.NET Core REST API, and an ASP.NET Core MVC admin panel for clinics.

- Each clinic's data is isolated at the query level with EF Core global query filters
- Appointment booking with a request-and-approve flow
- Push notifications through Firebase Cloud Messaging
- A library of 181 exercise videos made with physiotherapist partners
- Full Arabic and English support
- Deployed on Railway with Docker and PostgreSQL

### Manoly Warehouse

A warehouse management system for a wood trading company, now in daily use by its staff. It replaced a paper and Excel workflow and tracks 432 shelf positions, 420+ products, and purchase orders.

Built with ASP.NET Core 8 MVC, EF Core, PostgreSQL, and Tailwind CSS. Deployed on Fly.io.

### Uncle Lee Chi

A food ordering app for a restaurant with two branches. Flutter frontend with an ASP.NET Core and JWT backend.

### RamiLine

A business management web app for a client. I maintain it, add features, and handle deployments. Built with ASP.NET Core, SQL Server, and Angular.
